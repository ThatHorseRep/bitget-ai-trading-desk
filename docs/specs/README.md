# Specifications & Prompt History

Working documents from the build process: the B01–B07 product
specifications, the optional-toolkit expansion specs (PRE24 series), the
implementation prompt book, and the running pending-tasks ledger.

These are **process artifacts, not product documentation**. The
submission-facing documents live at the repository root
(`README.md`, `PRODUCT_DESCRIPTION.md`, `SUBMISSION.md`,
`ARCHITECTURE_AND_LIMITATIONS.md`); engineering reference docs live in
`docs/`. Nothing in this folder is loaded, imported, or shipped by the
application.
