## 2. Whether It Is Currently LLM-Generated

- `thesisQuality`: **YES, LLM-GENERATED**. The prompt asks the model to classify `thesisQuality` as `"STRONGER" | "MIXED" | "WEAKER" | "INSUFFICIENT"`, and parses this string from the LLM JSON response.
- `positionQuality`: **NO, DETERMINISTIC**. Computed by `classifyPositionQuality` in TypeScript math.

## 3. Every Place Consumed

1. **`src/core/decision/policy.ts`** (`evaluateDecisionPolicy`):
   - Evaluates `inputs.thesisQuality` and `inputs.positionQuality` across branching rules to return final verdict (`REJECT`, `WARN`, `APPROVE`), policy reasons, blockers, and change conditions.
2. **`src/services/decisionDeskService.ts`** (`runWorkflow`):
   - Packages `thesisQuality` and `positionQuality` into `DecisionArtifact` and feeds them into `evaluateDecisionPolicy(policyInputs)`.
3. **`src/core/thesis/narrativeCache.ts`** (`getNarrative`):
   - Maps `positionQuality` string to fallback narrative templates.
4. **`src/components/workspace/DecisionArtifactView.tsx`**:
   - Renders visual badges (`STRONGER` in green/slate, `WEAKER` in amber/red) and displays reasons list.
5. **`src/fixtures/rnvda-demo.ts`**:
   - Stores pre-baked fixture baseline values.

## 4. Current Thresholds and Decision Branches

In `src/core/decision/policy.ts` (`evaluateDecisionPolicy`), the exact decision tree was:

1. **Missing Data Check**:
   If critical data fields missing -> `REJECT` (Reason: `CRITICAL_DATA_BLOCKER`).
2. **Insufficient Thesis Branch**:
   If `inputs.thesisQuality === "INSUFFICIENT"`:
   -> Verdict: `REJECT` (Reason: `INSUFFICIENT_THESIS`).
3. **Double Weakness Branch**:
   If `inputs.thesisQuality === "WEAKER" && inputs.positionQuality.quality === "WEAKER"`:
   -> Verdict: `REJECT` (Reasons: `THESIS_CONTRADICTED`, `SEVERE_POSITION_RISK`).
4. **Off-Hours Weakness Branch**:
   If `isWeekendOrOffHours && inputs.positionQuality.quality === "WEAKER"`:
   -> Verdict: `REJECT` (Reasons: `OFF_HOURS_EXECUTION_RISK`, `SEVERE_POSITION_RISK`).
5. **Isolated Position Weakness**:
   If `inputs.positionQuality.quality === "WEAKER"`:
   -> Verdict: `WARN` (Reason: `ELEVATED_POSITION_RISK`, change condition: resize position or hedge basis).
6. **Thesis Support & Default**:
   - If `inputs.thesisQuality === "STRONGER" || inputs.thesisQuality === "MIXED"`:
     Adds supporting policy reason.
   - If `inputs.positionQuality.quality === "STRONGER"` with acceptable conditions:
     -> Verdict: `APPROVE`.
   - Default fallback: `WARN`.
